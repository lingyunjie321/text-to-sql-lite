# 04 - 响应式设计

## 1. 断点定义

对齐 Tailwind CSS 默认断点：

| 断点 | 前缀 | 最小宽度 | 设备 | 本次设计策略 |
|------|------|----------|------|-------------|
| 默认 | (无) | 0px | 手机（竖屏） | 移动端布局 |
| sm | `sm:` | 640px | 手机（横屏）/ 小平板 | 移动端布局微调 |
| md | `md:` | 768px | 平板（竖屏） | 平板布局 |
| lg | `lg:` | 1024px | 平板（横屏）/ 小桌面 | 桌面端布局 |
| xl | `xl:` | 1280px | 桌面 | 桌面端布局（内容区达最大宽） |
| 2xl | `2xl:` | 1536px | 大桌面 | 同 xl，居中 |

### 本次重点关注的三个区间

```
移动端          平板端            桌面端
< 768px      768 - 1023px      ≥ 1024px
│                │                  │
│  底部 Tab       │  顶部导航          │  顶部导航
│  单列布局       │  单列布局          │  单列布局（工作台）
│  输入区吸底     │  输入区内嵌        │  输入区内嵌
│  表格横滚       │  表格横滚          │  表格横滚（列多时）
│  图表自适应     │  图表自适应        │  图表自适应
```

## 2. 桌面端布局策略（≥ 1024px）

### 2.1 工作台页面

```
┌─────────────────────────────────────────────────────────────────────┐
│  [Logo] Text-to-SQL    工作台  历史  帮助  关于           [GitHub]    │  TopNav h-14
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                             │   │
│  │  欢迎区 / 对话流区                                            │   │  max-w-[1200px]
│  │  (max-width: 1200px, mx-auto)                               │   │  mx-auto
│  │                                                             │   │  px-6
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  底部输入区 (内嵌, max-w-[1200px])                           │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**桌面端关键决策**：

1. **内容区最大宽度 1200px**：数据表格需要足够宽度，但不超过 1200px 避免在超宽屏上阅读困难
2. **输入区内嵌**：不吸底，跟随内容流滚动，与对话流形成连贯的聊天体验
3. **表格横向滚动**：列数多时允许横向滚动，表头粘性固定
4. **图表全宽**：Recharts `<ResponsiveContainer>` 自适应容器宽度，高度固定 400px

### 2.2 宽屏利用（≥ 1280px）

在 xl 及以上断点，内容区达到 1200px 最大宽度后居中，两侧留白。不做额外分栏，保持聊天式工作台的单列聚焦体验。

**平板端关键调整**：

1. 内容区宽度 100%，去掉最大宽度限制（或设为 1024px）
2. 导航栏保持顶部导航，但简化右侧内容
3. 表格和图表保持全宽
4. 输入区仍内嵌在内容流中

### 3.2 与桌面端的差异

| 方面 | 桌面端 (≥1024px) | 平板端 (768-1023px) |
|------|-------------------|---------------------|
| 内容区宽度 | max-w-[1200px] | max-w-[100%] 或 max-w-[1024px] |
| 水平内边距 | px-6 (24px) | px-6 (24px) |
| 导航栏 | 完整导航项 | 完整导航项 |
| 输入区 | 内嵌 | 内嵌 |
| 表格 | 全宽 + 横滚 | 全宽 + 横滚 |

```
┌─────────────────────────────────────┐
```

```
│  工作台    历史      帮助     关于    │
```

- 高度：56px (`h-14`)
- 固定底部：`fixed bottom-0 left-0 right-0 z-50`
- 背景：`bg-white border-t border-gray-200`
- 4 个 Tab 等分宽度：`grid grid-cols-4`
- 当前页高亮：图标和文字变为主色 `text-primary`
- 非当前页：`text-gray-400`
- 图标 24px，文字 `text-xs`

> **注意**：吸底输入区在 Tab Bar 上方。输入区 `fixed bottom-14`（在 Tab Bar 之上），主内容区 `pb-32`（同时为输入区和 Tab Bar 预留空间）。

### 4.4 表格在移动端的处理

#### 策略一：横向滚动（默认）

列数 ≤ 4 时，保持表格形式，容器横向滚动。

```
┌─────────────────────────────────────┐
│ [表格] [柱状图] [折线图]              │
├─────────────────────────────────────┤
│ ┌───────────────────────────────←→─┐│  ← overflow-x-auto
│ │ title      │ revenue │ count     ││
│ ├────────────┼──────────┼──────────┤│
│ │ TELEMARK...│ $231.73  │ 8         ││
│ │ VOYAGE...  │ $216.97  │ 7         ││
│ └───────────────────────────────────┘│
└─────────────────────────────────────┘
```

- 容器：`overflow-x-auto`
- 表格：`min-w-full`（至少占满容器宽度，列多时超出滚动）
- 首列可选粘性：`sticky left-0 bg-white`（保持关键列可见）

#### 策略二：卡片化（列数 > 4 时）

列数过多时，表格横向滚动体验差，改为卡片列表形式。

```
┌─────────────────────────────────────┐
│ 共 10 条结果                          │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ title: TELEMARK...               │ │
│ │ total_revenue: $231.73           │ │
│ │ rental_count: 8                  │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ title: VOYAGE...                 │ │
│ │ total_revenue: $216.97           │ │
│ │ rental_count: 7                  │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

- 每行数据转为一张卡片
- 列名作为标签（key），列值作为内容（value）
- 卡片间距：`gap-2`
- 卡片样式：`bg-gray-50 rounded-md p-3 text-sm`

#### 切换规则

| 列数 | 移动端展示方式 |
|------|---------------|
| ≤ 4 列 | 横向滚动表格 |
| > 4 列 | 卡片化列表 |

> 此规则仅移动端（< 768px）生效。平板和桌面端始终使用表格形式 + 横向滚动。

- 图例：底部排列，可滚动
- Tooltip：触摸点击触发（而非悬停）

## 6. Tailwind 响应式工具类使用规范

### 6.1 Mobile-First 原则

Tailwind 采用 Mobile-First 策略：无前缀的类适用于最小屏幕，带前缀的类从该断点开始生效。

```tsx
// 正确：先写移动端样式，再逐步增强
<div className="
  px-4           /* 移动端：16px 内边距 */
  md:px-6        /* 平板+：24px 内边距 */
  lg:max-w-[1200px] lg:mx-auto  /* 桌面端：最大宽度 + 居中 */
">
```

```tsx
// 错误：不要先写桌面端再降级
<div className="
  px-6 max-w-[1200px] mx-auto   /* ❌ 这样移动端也会有最大宽度 */
  sm:px-4                        /* ❌ Mobile-First 下 sm: 是增强不是降级 */
">
```

### 6.2 常用响应式模式

#### 内容区宽度

```tsx
<main className="
  w-full px-4           /* 移动端：全宽 + 16px 内边距 */
  md:px-6               /* 平板+：24px 内边距 */
  lg:max-w-[1200px] lg:mx-auto  /* 桌面端：最大 1200px 居中 */
">
```

#### 导航栏

```tsx
{/* 桌面端顶部导航 */}
<nav className="hidden md:flex h-14 ...">
  {/* 导航项 */}
</nav>

{/* 移动端底部 Tab Bar */}
<nav className="fixed bottom-0 left-0 right-0 h-14 md:hidden ...">
  {/* Tab 项 */}
</nav>
```

#### 输入区

```tsx
{/* 桌面端：内嵌 */}
<div className="md:relative md:bottom-auto">
  <InputDock />
</div>

{/* 移动端：吸底 */}
<div className="fixed bottom-14 left-0 right-0 md:hidden">
  <InputDock />
</div>
```

#### 表格

```tsx
<div className="overflow-x-auto">
  <table className="min-w-full">
    {/* 表格内容 */}
  </table>
</div>
```

#### 图表高度

```tsx
<ResponsiveContainer
  width="100%"
  height={300}  // 移动端 300px
  className="md:h-[400px]"  /* 桌面端 400px — 需通过包裹 div 控制 */
>
```

> **注意**：Recharts 的 `height` prop 不支持 Tailwind 类。需通过 JS 检测视口宽度或使用 CSS 覆盖。推荐方案：用 `useMediaQuery` hook 动态设置高度。

```tsx
const isDesktop = useMediaQuery('(min-width: 768px)');
<ResponsiveContainer width="100%" height={isDesktop ? 400 : 300}>
```

### 6.3 常用断点类组合速查

| 场景 | 类名 |
|------|------|
| 仅移动端显示 | `md:hidden` |
| 仅桌面端显示 | `hidden md:flex` / `hidden md:block` |
| 移动端全宽，桌面端居中限宽 | `w-full lg:max-w-[1200px] lg:mx-auto` |
| 移动端 16px，桌面端 24px 内边距 | `px-4 md:px-6` |
| 移动端单列，桌面端多列 | `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3` |
| 移动端吸底，桌面端内嵌 | `fixed bottom-14 md:static md:bottom-auto` |

## 7. 触摸交互优化（移动端）

| 优化项 | 说明 |
|--------|------|
| 最小触摸目标 | 所有可点击元素最小 44x44px（iOS HIG 标准） |
| 按钮间距 | 相邻按钮间距 ≥ 8px，避免误触 |
| 表格行高 | 移动端表格行高 ≥ 48px，便于触摸滚动 |
| 图表 Tooltip | 触摸点击触发（非悬停），点击空白关闭 |
| 输入框聚焦 | 聚焦时页面不缩放：`font-size: 16px`（iOS 低于 16px 会自动缩放） |
| 滚动惯性 | 滚动容器添加 `-webkit-overflow-scrolling: touch` |
| 长按选择 | 禁用非文本区域的长按选择：`-webkit-user-select: none` |
