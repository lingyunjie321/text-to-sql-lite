### 导航关系说明

1. **首页 / 工作台（`/`）** 是核心页面，承担查询输入和结果展示的全部职责，采用**对话式单页**设计
2. **历史记录（`/history`）** 点击某条记录后，跳转回首页 `/` 并恢复该对话上下文
3. **帮助（`/help`）** 中的示例问题可一键跳转首页并自动填入提交
4. **设置（`/settings`）** ★新增 配置模型和数据源连接，保存到 localStorage；查询时工作台自动读取配置并附加到请求中
5. **关于（`/about`）** 纯静态信息页，无交互跳转

## 3. 各页面核心职责

| 页面 | 路由 | 核心职责（一句话） |
|------|------|---------------------|
| 首页 / 工作台 | `/` | 提供自然语言查询输入和结果展示的对话式工作台 |
| 历史记录 | `/history` | 浏览、搜索、恢复、删除历史查询记录（localStorage） |
| 帮助 | `/help` | 提供使用指南和分类示例问题，降低上手门槛 |
| 设置 | `/settings` | 配置 LLM 模型（轻量/标准/高强度 + fallback）和数据库连接，存 localStorage |
| 关于 | `/about` | 展示项目信息、技术栈和数据源说明 |

## 4. 路由设计（Next.js App Router）

```
src/app/
├── layout.tsx              # 根布局：全局字体、TopNav、BottomTabBar、Provider
├── page.tsx                # 首页 / 工作台（/）
├── history/
│   └── page.tsx            # 历史记录（/history）
├── help/
│   └── page.tsx            # 帮助（/help）
├── settings/               # ★新增
│   └── page.tsx            # 设置（/settings）：模型配置 + 数据库配置
├── about/
│   └── page.tsx            # 关于（/about）
└── api/
    └── v1/
        └── text-to-sql/
            └── route.ts    # BFF 代理：转发请求到后端 FastAPI
```

### 路由设计要点

1. **BFF 代理路由**：`/api/v1/text-to-sql/route.ts` 作为 Route Handler，将前端请求转发到后端 FastAPI 的 `POST /api/v1/text-to-sql`。这样做的好处：
   - 前端不直接暴露后端地址
   - 可在代理层注入 API Key（从环境变量读取）
   - 统一错误处理和超时控制

2. **首页采用客户端组件**：查询工作台有大量交互状态（输入、加载、结果、澄清等），首页主体使用 `"use client"` 声明为客户端组件

3. **历史记录页**：纯客户端页面，数据来自 localStorage，无需服务端渲染

4. **帮助/关于页**：静态内容，可使用 Server Component 直接渲染，利于 SEO 和首屏速度

5. **设置页** ★新增 纯客户端页面，配置数据存 localStorage。包含模型配置（3 种模型卡片 + fallback）和数据库连接配置（数据源类型 + 连接参数 + 授权）。查询时工作台自动读取 localStorage 配置并附加到查询请求中。详见 [07-settings-page.md](./07-settings-page.md)。

### 动态路由（可选扩展）

当前不需要动态路由。历史记录恢复通过 localStorage 读取后直接在首页恢复对话状态，不使用 URL 参数。如果未来需要分享查询链接，可扩展为 `/q/[requestId]` 动态路由。

## 5. 导航布局选择：顶部导航栏

### 选择方案：顶部导航栏（TopNav）

```
┌─────────────────────────────────────────────────────────────────────────┐
│  [Logo] Text-to-SQL   工作台 历史 帮助 设置 关于              [GitHub]    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│                     页面内容区                                            │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 选择理由

| 考量 | 顶部导航 | 侧边栏 | 决策 |
|------|----------|--------|------|
| 内容宽度 | 全宽利用 | 占用 240px 左侧空间 | ✅ 顶部导航 |
| 移动端适配 | 自然降级为底部 tab | 需要汉堡菜单 | ✅ 顶部导航 |
| 页面类型 | 工具型应用，页面少（5个） | 仪表盘型，页面多 | ✅ 顶部导航 |
| 视觉焦点 | 不抢占主内容区宽度 | 持续占用左侧 | ✅ 顶部导航 |
| 纵向空间 | 占用 56px 顶部高度 | 不占用纵向 | 侧边栏占优，但影响不大 |

**结论**：本项目是工具型应用，页面数量少（5个），核心页面（工作台）需要最大化内容宽度以展示数据表格。顶部导航栏是最佳选择。

### 导航栏规格

- 高度：56px（`h-14`）
- 固定在顶部：`sticky top-0 z-50`
- 背景：白色 + 底部 1px 边框（`border-b border-gray-200`）
- 内容：左侧 Logo + 应用名，中间导航链接，右侧外部链接
- 导航项：当前页高亮（文字主色 + 下方 2px 指示条）
- 导航项数量：5 个（工作台 / 历史 / 帮助 / 设置 / 关于）

### 移动端导航降级

- < 768px：顶部导航栏只保留 Logo + 汉堡菜单按钮
- 点击汉堡菜单展开抽屉式导航
- 或者使用底部 Tab Bar（5 个图标 + 文字），更符合移动端操作习惯

```
移动端 (< 768px) — 底部 Tab Bar:

┌───────────────────────────────────────────┐
│                                           │
│                页面内容区                   │
│                                           │
│                                           │
├───────────────────────────────────────────┤
│ [🏠]   [📜]   [❔]   [⚙️]   [ℹ]            │
│ 工作台  历史   帮助   设置   关于            │
└───────────────────────────────────────────┘
```

> 移动端最终选择底部 Tab Bar（而非汉堡菜单），因为：底部 Tab 可直达、可见性好、符合移动端拇指操作区域。新增「设置」后从 4 项增至 5 项，375px 宽度下每项约 75px，仍满足最小触摸目标 44px 要求。详见 [04-responsive-design.md](./04-responsive-design.md)。

## 6. 全局布局结构

```
┌─────────────────────────────────────────────────────────┐
│                    TopNav (h-14, sticky)                  │  ← 所有页面共享
├─────────────────────────────────────────────────────────┤
│                                                         │
│                                                         │
│                    主内容区 (main)                        │  ← 各页面独立
│                    max-width: 1200px                     │
│                    mx-auto, px-4/px-6                    │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                    Footer (可选, h-12)                    │  ← 所有页面共享
└─────────────────────────────────────────────────────────┘
```

### 布局参数

| 参数 | 桌面端 (≥1024px) | 平板 (768-1023px) | 移动端 (<768px) |
|------|-------------------|-------------------|-----------------|
| 内容区最大宽度 | 1200px | 100% | 100% |
| 内容区水平内边距 | 24px (px-6) | 24px (px-6) | 16px (px-4) |
| TopNav 高度 | 56px (h-14) | 56px (h-14) | 56px (h-14) |
| 底部输入区 | 内嵌在内容流中 | 内嵌在内容流中 | fixed 底部吸底 |

> **注意**：首页（工作台）的底部输入区在移动端采用 `fixed bottom-0` 吸底设计，为输入区预留空间，主内容区需增加 `padding-bottom` 避免遮挡。
