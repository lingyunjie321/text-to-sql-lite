# 本地安装与启动

## 适用范围

本项目是本地单用户 Web 工具：FastAPI 后端监听 `127.0.0.1:8000`，Next.js 前端
监听 `127.0.0.1:3000`。默认不对局域网或互联网开放。

## 准备环境

- Python 3.12～3.14
- Node.js 20.9.0+ 与 npm
- Git
- PostgreSQL 或 MySQL（使用自己的数据库时）
- OpenAI-compatible Chat Completions 服务；Embedding 可不配置

安装：

```bash
git clone https://github.com/lingyunjie321/text-to-sql-lite.git
cd text-to-sql-lite
python3.12 -m venv .venv
.venv/bin/python -m pip install '.[test]'
cd frontend
npm install
cd ..
```

安装过程不会要求数据库密码或模型 API Key。

## 统一启动

```bash
.venv/bin/text-to-sql-lite start
```

也可以运行 `make dev`。启动器会依次：

1. 检查 Python、Node.js、npm 和前端依赖；
2. 创建 `~/.text-to-sql-lite`；
3. 启动 FastAPI；
4. 向前端注入本地后端地址并启动 Next.js；
5. 两个服务就绪后打开浏览器。

常用选项：

```bash
.venv/bin/text-to-sql-lite start --no-open
.venv/bin/text-to-sql-lite start --backend-port 8100 --frontend-port 3100
```

端口变化由启动器同步给前端，无需再写 `TEXT_TO_SQL_API_URL`。如需静态 Pagila、
静态模型或 API Bearer Key，再按 [.env.example](../.env.example) 创建本地 `.env`；
完全使用 Profile 时可以没有 `.env`。

## 停止与本地数据

在启动终端按 `Ctrl+C`。启动器会停止前端和 Uvicorn，Uvicorn 的 ASGI lifespan
随后关闭动态/静态 Connector、模型运行时并清空内存凭据。若子进程在宽限时间内
不退出，启动器只会强制结束自己创建的子进程。

非敏感 Profile 保存在 `~/.text-to-sql-lite/config.db`。API Key 和数据库密码只在
当前后端进程内存中；重启后 Profile 仍在，但必须重新输入凭据。

## 当前界面边界

模型和数据库设置页均使用正式 Profile API。数据库页可以测试 PostgreSQL/MySQL、
读取 metadata、勾选允许查询的表或视图并设为当前数据源；工作台还要求选择当前模型。
浏览器只保存两个 Profile ID，凭据只随写请求进入后端进程内存。详见
[添加模型](添加模型.md) 与 [添加数据库](添加数据库.md)。
