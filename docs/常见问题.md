# 常见问题

## 启动提示找不到 Node.js、npm 或 Next.js

确认 `node --version` 和 `npm --version` 可用，然后在 `frontend` 目录运行
`npm install`。启动器不会擅自联网安装依赖。

## 端口被占用

结束占用 8000/3000 的旧进程，或运行：

```bash
.venv/bin/text-to-sql-lite start --backend-port 8100 --frontend-port 3100
```

## 浏览器没有自动打开

手动访问终端显示的前端地址。远程或无图形环境建议加 `--no-open`。

## 重启后 Profile 还在，但提示凭据缺失

这是预期安全行为。非敏感 Profile 存在 SQLite，API Key 和数据库密码只存在进程
内存。重新编辑模型或数据源 Profile 并提交凭据即可。

## 没有 Embedding 能否查询

可以。未配置 Embedding 时走 BM25-only；Embedding 发生可降级故障且存在同授权、
同 Schema 版本的安全 BM25 候选时，也会回退到 BM25 并记录脱敏原因。

## 本地模型地址为什么被拒绝

HTTP 只允许 `localhost`、`127.0.0.1` 或 IPv6 loopback。远程服务必须使用 HTTPS；
URL 不能带用户名、密码、query 或 fragment。

## 编辑数据源时为什么测试连接仍要重新输入密码

已保存密码只存在后端进程内存，编辑表单不会回显或从后端读取 Secret。保存时留空表示
保留当前密码；但连接测试是独立临时请求，不会复用已保存密码，因此测试前需要重新输入。

## 保存数据源时 allowlist 验证失败

确认账号能看到对应对象、`allowed_tables` 使用 `schema.table`、其 Schema 已列入
`allowed_schemas`，并检查表是否在连接测试结果中。发现 metadata 不会自动授权表。

## 查询返回 404、409、503 或 504

- 404：Profile 不存在；
- 409：凭据缺失、allowlist 无效或 Profile 无法绑定；
- 503：数据库、模型或运行时不可用；
- 504：metadata 或外部调用超时。

这些错误不会回退到默认资源。查看公开错误码，不要把数据库驱动原文或 Secret 发到
日志、Issue 或聊天中。

## Ctrl+C 后连接会关闭吗

会。统一启动器终止 Uvicorn，ASGI lifespan 会关闭 Registry 与 Connector 并清空
内存凭据。如果子进程拒绝正常退出，启动器会在宽限期后强制结束它。
